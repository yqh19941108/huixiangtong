# 惠享通 · 福利测算

![惠享通封面](cover.svg)

> 你该领的钱，别让它躺着过期。

输入所在城市与你的处境（在职 / 失业 / 学历 / 家庭情况…），10 秒算出你**能申领的每一笔福利**——不只是发钱，连"失业期间国家帮你缴医保"这类隐性福利也一并告知。

## ✨ 特色

- 🧮 **一键匹配**：覆盖失业保障 / 收入兜底 / 住房 / 医疗 / 养老 / 育儿 / 残疾 / 退役 / 人才 9 大类福利
- 💰 **现金 + 非现金**：金额估算之外，明确标注"代缴 / 免费 / 优待"类隐性福利（如失业期间医保国家全额代缴）
- 🧭 **照着办**：每条附粤省事 / 政务服务网的精确板块路径与标准事项名，不再进官网迷路
- 🔒 **纯前端**：计算全在本地浏览器完成，**不上传任何个人信息**
- 🆓 **零成本**：纯静态站，可免费托管 GitHub Pages，政策变动只改 `policies.js` 一个文件
